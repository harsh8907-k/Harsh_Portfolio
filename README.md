## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm`

### Installation

```bash
# Clone the repository
git clone https://github.com/harsh8907-k/Harsh_Portfolio.git

# Navigate into the project folder
cd Harsh_Portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
```
